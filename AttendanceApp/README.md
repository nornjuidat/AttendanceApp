# Attendance Clock

אפליקציית שעון נוכחות מקומית שנבנתה באמצעות React Native ו-Expo Router.

## יכולות

- התחברות עם שם משתמש וסיסמה.
- כניסה ויציאה ממשמרת.
- שמירת תאריך, שעה ומיקום.
- חישוב משך משמרת.
- שמירה קבועה ב-AsyncStorage.
- היסטוריית משמרות.
- מסך פרטי משמרת.
- ניהול שם משתמש, סיסמה ותמונת פרופיל.
- בחירת תמונה מהגלריה או צילום במצלמה.
- Drawer, Tabs ומסך Not Found.
